# How to Create *.proj Files for slngen

## Purpose
A `.proj` file allows slngen (Single Project Generator) and other build tools to build a complete project by importing multiple `.csproj` files into a single build unit.

## Structure
```xml
<Project>
  <Import Project="MainProject.csproj" />
  <Import Project="Tests\TestProject.csproj" />
</Project>
```

## Key Points
1. **Use `<Import>` tags** - Each `.csproj` file is imported as a separate project
2. **Relative paths** - Use relative paths from the `.proj` file location
3. **No duplicate properties** - Don't define properties that are already in the imported `.csproj` files
4. **Place in project root** - Typically in the same directory as the main `.csproj` or in a subdirectory

## When to Use
- Multi-project solutions that need to be built as a single unit
- CI/CD pipelines using slngen
- Container builds that need all projects in one place

## Example
For a project with:
- `CaPPMS.csproj` (main site)
- `unitests/CaPPMSTests.csproj` (tests)

Create `CaPPMS.proj`:
```xml
<Project>
  <Import Project="CaPPMS.csproj" />
  <Import Project="unitests\CaPPMSTests.csproj" />
</Project>
```

## Build with slngen
```bash
slngen build CaPPMS.proj
```
